蘇清的枪械商店固定收购 1.1.0
适用：Project Zomboid Build 42.21 单人；需要 ModernFirearmsSystem。

打开方式
身上带对讲机，右键枪械“检视武器”，点击原商店对讲机按钮。
上半部分为常驻收购，下半部分为原来的随机装备商店。
默认仅显示当前可售物品；取消“只显示持有物品”可浏览全部清单。
分类菜单可筛选钱款、首饰、宝石、手表和贵金属材料。
每行“卖1件”只出售一件，“全部”出售该行型号的全部可售物品。
新增“一键出售”：一次出售所有类别中符合条件的随身物品，包括普通背包内部物品。
一键出售不受当前分类筛选影响；按钮上显示全部可售件数和预计收入。
交易结束后显示实际出售件数和到账金额，没有额外的逐类确认窗口。

1.1.0 修复与改进
修复单人交易完成后仍显示“核对交易”、等待8秒才能继续的问题。
上一版在单人模式等待网络回执，而游戏的sendServerCommand仅在服务器模式发送。
新版单人直接调用同一套交易校验和结算逻辑，完成后立即更新界面。
一键出售一次核对所有型号、一次扣物、一次入账；不再逐类等待。

默认收购范围：122项，五类均默认开启
钱款4项、贵重首饰88项、独立宝石5项、手表怀表17项、贵金属材料8项。
全部为已核对的原版具体物品ID，不根据中文名相似程度收购。
骨饰、狗牌、友谊手链、普通黑项圈、钥匙环及其它随机纪念品不在名单中。

默认单件价格（交易币）
钞票10；捆装钞票1000；银币50；金币250。
普通银饰100；普通金饰及金印章戒指300。
镶宝石、珍珠和琥珀首饰800；独立钻石/红宝石/蓝宝石/翡翠/紫水晶1000。
经典或电子腕表100；军用腕表150；金色腕表300；豪华腕表500；怀表300。
金碎片25；金板250；小金锭1000；金锭8000。
银碎片5；银板50；小银锭100；银锭800。
完整型号、来源与价格见开发目录 validation/catalog_manifest.json 或导出的价目表。

保护规则
收藏、手持、正在佩戴的物品不会出售。
收藏的包或钱包会保护其中所有物品；解除该容器收藏后，其内部未收藏物品才可出售。
正在背着的普通背包内部物品仍可出售，背包本体不属于收购清单。
客户端不提供成交价格；成交时重新核对可售物品与单价。
批量出售先检查再扣物；跨型号一键出售也使用同一笔事务。
扣除或入账失败会尝试恢复整笔交易的原物品与余额。

原有商店行为
沿用原 MFSTrade_Money 余额；不赠送交易币，不改变已有余额。
商人出售的7件随机装备、每12游戏小时刷新、原购买流程均保留。
只有收购清单和收购价格固定。
关闭沙盒中的“启用固定收购”或停用本模组、重启游戏后恢复原来的随机收购。
已成交获得的余额仍保留；停用不会撤销之前已完成的交易。

开关与价格
沙盒设置中“蘇清·商店固定收购”提供首饰、宝石、手表、贵金属分类开关和价格倍率。
首饰、宝石、手表和贵金属全部默认开启；钱款始终包含在启用后的收购名单内。
旧存档没有保存这些新增字段时使用上述默认值，不需要改写 map_sand.bin。
如需给现有存档改分类，可使用你已有的沙盒设置编辑入口，然后正常保存重进。

游戏内集中检查（一次完成）
1. 带对讲机和少量不同种类的钞票/钱币/首饰，另收藏一件、佩戴一件首饰。
2. 打开商店点击“一键出售”，应一次结算全部类别，立即显示出售数量和收入。
3. 确认收藏、佩戴的物品仍在；仅切换分类不会限制一键出售范围。
4. 每行“卖1件”和“全部”仍仅处理该型号，正常单人交易不再等待8秒。
5. 购买一件原商店装备；保存退出并重进，确认余额与剩余物品正确。

本模组为独立本地补丁，没有覆盖工坊文件，不会启用 SuPerfCore 或 ZombieBuddy。
